# Models

GitHub 不包含 axmodel。请从 HuggingFace 下载 `models/` 目录。

本 release 支持 8 kHz / 16 kHz 输入，48 kHz 输出；每个采样率包含 3 个子模型：

```text
universr_split_8k_condenc.axmodel
universr_split_8k_main_cond_actual.axmodel
universr_split_8k_main_uncond.axmodel
universr_split_16k_condenc.axmodel
universr_split_16k_main_cond_actual.axmodel
universr_split_16k_main_uncond.axmodel
```
